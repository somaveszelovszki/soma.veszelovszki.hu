micro-utils

Portable C++ libraries for embedded systems

  • GitHub

The shared foundation of the babocar firmware. The libraries don't depend on anything an embedded standard library might leave out, and they use static memory allocation only: every container has a fixed capacity known at compile time.

The port layer hides the hardware and the OS behind one interface, with STM32 HAL, FreeRTOS and mock implementations. The same control code runs on the car and in GoogleTest unit tests on a laptop. Hot paths are measured with Google Benchmark.

Libraries

container
vector, map, set and ring buffer with static allocation
control
PID controller, ramps, maneuvers
sensor
filters and a Madgwick AHRS for sensor fusion
hw
drivers for motors, encoders, IMUs, distance sensors and LCDs
port
hardware and OS abstraction layer
panel
protocols and data structures shared between the car's units
math
linear algebra and numeric helpers
others
debug, log, format, json, sim, test, utils
