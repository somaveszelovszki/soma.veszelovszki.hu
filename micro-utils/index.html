Overview

The shared foundation of the babocar firmware. Every container has a fixed capacity known at compile time, so there are no heap allocations or fragmentation. Built on the Embedded Template Library.

The port layer hides hardware and OS behind one interface, with STM32 HAL, FreeRTOS and mock implementations. The same control code runs on the car and in GoogleTest unit tests on a laptop; hot paths are measured with Google Benchmark.
